# Google indexing setup

The site now publishes crawlable metadata, local restaurant structured data,
`/robots.txt`, `/sitemap.xml`, and a social sharing image automatically.

## One-time production setup

1. Set `NEXT_PUBLIC_SITE_URL` to the exact public origin (including `https://`,
   without a trailing slash).
2. Add the site as a URL-prefix property in Google Search Console.
3. Choose the HTML tag verification method and copy only its `content` value
   into the `GOOGLE_SITE_VERIFICATION` deployment environment variable.
4. Deploy, verify the property, then submit `https://tiffencentral.com/sitemap.xml`
   in Search Console once.

Google will subsequently rediscover the sitemap through `robots.txt`, and the
sitemap is regenerated by each production build. Google's Indexing API is not
used because Google limits it to job posting and livestream pages, not ordinary
restaurant websites.

## Ranking follow-through

Keep the restaurant name, address, phone, opening hours, and website URL exactly
consistent on the site, Google Business Profile, Instagram, and food directory
listings. Add genuine customer reviews and current food/location photos to the
Business Profile. Technical SEO enables crawling; it cannot guarantee a search
position.
